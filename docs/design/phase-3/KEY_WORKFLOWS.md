# Phase 3 Key Workflows (Draft)

1. **Party create** — select shared vs branch scope; add ≥1 role; transporter/driver attribute validation; audit on mutate.
2. **Party role remove** — remark required; retain role attribute payload; block removing last active role.
3. **Document attach** — upload → scan gate → available; replace keeps old until new succeeds.
4. **Subscription draft** — select plans/add-ons/tenure → pricing breakdown → immutable snapshot (no payment activation in UI until G-PAY).
5. **Owner billing** — list invoices; approve number only (no rejection); email failure does not reverse approval.
